# GODest - Hyderabad Premier Mobility Platform

Official web application for **GODest** (Hyderabad, India), providing 24x7 Car Cabs, Bike Taxis, and Auto Rickshaws with 100% verified captains and transparent zero-surge pricing.

## Features
- **3-in-1 Mobility**: Car, Bike Taxi, and Auto Rickshaw booking simulation.
- **Dynamic Fare Calculator**: Transparent calculation for city trips, Rajiv Gandhi International Airport (RGIA), and outstation pilgrimage routes.
- **Hyderabad Corridors**: Real-time fare comparisons across popular city routes.
- **Poster Brand Aesthetic**: Clean Taxi Yellow (`#F5B800`) and Royal Blue (`#2563EB`) design inspired by the official brand poster.
- **Responsive & Modern**: Built with React, Tailwind CSS v4, Lucide vector icons, and Vite.

## Tech Stack
- **React 19**
- **Vite 8**
- **Tailwind CSS v4** (`@tailwindcss/vite`)
- **Lucide React** (Vector SVG icons)

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
